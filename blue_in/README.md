# 블루인 (bluein)

현장 기술자와 기업을 연결하는 한국어 커리어 웹사이트입니다. 링크드인의 상단 내비게이션, 프로필 사이드바, 피드형 카드 구조를 참고하고 블루인만의 파란색 디자인을 적용했습니다.

## 바로 열기

- 화면 확인: 이 폴더의 `index.html`을 더블 클릭합니다.
- 전체 실행: Node.js 22 이상에서 `start.bat`을 실행한 뒤 http://localhost:4173 을 엽니다. 또는 이 폴더에서 `npm start`를 실행합니다.
- 별도 패키지 설치는 필요 없습니다. 인터넷이 없으면 시스템 글꼴로 표시됩니다.

## 구현 기능

- 한국어 홈 피드와 반응형 모바일 화면
- 이름, 직무, 경력, 지역, 희망 연봉, 보유 기술, 자격증, 경험 소개 편집
- 프로필에 따른 채용 추천 순위와 항목별 매칭 점수 및 이유
- 직무 필터, 기업/직무/기술 검색, 채용 상세, 저장, 관심 지원 기록 및 취소
- 기업 채용 조건 등록과 현재 프로필의 적합도 비교
- 현장 이야기 작성, 공감, 댓글
- localStorage를 통한 현재 브라우저의 프로필과 입력 내용 유지
- 선택적 OpenAI 서버 연동 및 오류 시 조건 매칭으로 복귀

## 실제 AI 연결

1. `.env.example`을 복사해 `.env`로 저장합니다.
2. `OPENAI_API_KEY`에 자신의 OpenAI API 키를 입력합니다. 키는 브라우저에 보내지 않습니다.
3. 필요한 경우 `OPENAI_MODEL`을 계정에서 사용 가능한 구조화 출력 지원 모델로 변경합니다.
4. 서버를 재시작하고 **AI 매칭 → AI로 매칭 분석하기**를 누릅니다.

AI 분석 버튼을 누르면 이름 필드를 제외한 프로필과 채용 조건이 OpenAI로 전송됩니다. 자유 입력란에 적은 개인정보는 자동으로 제거되지 않으므로 필요한 업무 경험만 입력하세요. API 사용 요금이 발생할 수 있습니다. 키가 없거나 HTML을 직접 열면 조건 매칭으로 동작합니다. AI 응답은 검증 후 화면에 표시합니다. AI 분석은 선택적으로 실행되며, 프로필 또는 공고 변경 시 기존 AI 결과를 폐기하고 조건 점수를 재계산합니다.

API 구현 참고: [OpenAI 공식 구조화 출력 문서](https://developers.openai.com/api/docs/guides/structured-outputs). Responses API의 `text.format` JSON Schema를 사용합니다.

## 매칭 기준

기술 35점, 자격증 20점, 경력 20점, 지역 15점, 연봉 10점. 기본 조건 매칭은 입력한 기술·자격증 명칭의 정확한 일치로 계산합니다. AI 모드는 관련 기술과 경험 소개도 비교합니다. 점수는 참고용 적합도이며 채용 결정이나 합격 확률이 아닙니다.

## 로컬 데모 범위

기본 기업·공고·게시물은 모두 예시입니다. 관심 지원은 실제 기업에 전송되지 않습니다. 데이터는 현재 브라우저에만 저장되며 여러 사용자나 기기 간에 공유되지 않습니다. 기업 화면은 등록된 내 프로필 1건과 공고를 비교합니다. 로그인, 공용 데이터베이스, 기업 인증, 실제 지원 전송, 채팅, 파일 증빙 업로드, 공개 배포는 포함하지 않습니다. 실제 서비스 운영에는 이 기능들을 위한 백엔드와 계정 권한 관리가 필요합니다.

서버는 로컬 주소에만 바인딩하고 정해진 공개 파일만 제공합니다. `.env`는 정적 파일로 제공하지 않습니다. AI API를 실제 키로 호출하는 통합 검증은 키 설정 후 필요합니다. WebMCP 검색 도구는 해당 브라우저 API가 지원될 때만 등록되며 미지원 환경에서는 일반 화면 사용에 영향을 주지 않습니다.

## 파일

```text
blue_in/
  index.html       더블 클릭용 시작 페이지
  start.bat        Windows 로컬 서버 실행
  server.mjs       로컬 서버 및 선택적 AI 분석 API
  package.json     실행/문법 점검 명령
  .env.example     환경 설정 예시
  dist/
    index.html     웹사이트 화면
    styles.css     반응형 디자인
    app.js         데이터, 매칭, 화면 및 상호작용
```

`npm run check`로 JavaScript 문법을 검사할 수 있습니다.
